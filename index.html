INSTALL

安装要点

详细版随货附带，这里先看关键的几条——尤其第一条，不能省。

车侧接头X179 诊断接头，后排中央扶手后方饰板内（2021–2023 款为 20 针版）
必做核对接线前先进车辆服务模式 → CAN Port 页面，逐脚核对针脚对应的总线名称——不同线束布局至少有 4 种，不能只按年份猜
三路总线Party（2/3 脚）、Vehicle（9/10 脚）、Chassis（13/14 脚）；1 脚 +12V、20 脚 GND（以服务模式页面实测为准）
主板接线CAN1 TX GPIO20 / RX GPIO21 · CAN2 TX GPIO22 / RX GPIO23 · CAN3 TX GPIO26 / RX GPIO27
收发模块SN65HVD230 ×3：拆掉 120Ω 终端电阻、开启高速模式（特斯拉总线自带终端）
供电X179 的 12V 经降压模块转 5V 给主板供电
车机版本需要车机软件 ≥ 2026.20，低于此版本功能不正常
