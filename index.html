常见问题 FAQ

我的车能用吗？
适用于特斯拉 Model 3 / Y，车机软件需要 ≥ 2026.20（低于这个版本功能不正常）。下单/动手前先在车机里确认版本号。
REV1.X 和 REV3.X 固件怎么选？
看主板 ESP32-P4 芯片的版本：买成品的按卖家标注选；自己买板的看芯片丝印，或直接问板卡卖家。两个版本的固件包不通用，选错刷不上或运行异常。
第一次刷机怎么做？
用 FULLFLASH 整刷包：电脑 Chrome 打开 ESP 在线刷机工具（esp.huhn.me 或 adafruit WebSerial ESPTool），主板 USB 连电脑，选 merged 整刷包从地址 0x0 写入。
以后升级固件怎么做？
只能用 OTA 包：在模块网页仪表盘的固件更新入口上传 OTA 包，过程不要断电。千万别拿 FULLFLASH 整刷包当更新包刷——这是已知的模块重启故障原因。
模块装好后自己重启，怎么回事？
先查两件事：①是不是把整刷包当更新包刷了（重刷对应版本的 OTA 包纠正）；②供电是否稳定（12V 转 5V 的降压模块输出不足也会这样）。还不行就留言说明车型和刷的包名。
没买 EAP / FSD 能用吗？
基础功能可以正常用。但召唤、红绿灯识别（TLSSC）这类功能需要车辆本身已订阅 EAP / FSD 才能生效——本模块只做地区与距离等限制的解锁，不提供任何付费功能的破解。
接线难不难？要破线吗？
走后排 X179 诊断接头，不用破线。但接线前必须先进车辆服务模式的 CAN Port 页面，逐脚核对针脚对应的总线名称——不同年份线束布局至少有 4 种，不能只按年份猜。详细接线表在本站下载页下方。
装这个影响保修吗？
先说结论：整车还在特斯拉基本保修期内（4 年或 8 万公里，以先到为准）的，建议先别装，等出保后再考虑。安装涉及车辆 CAN 总线操作，特斯拉有可能据此拒绝相关部件甚至整车保修；已出保的车辆也请自行评估风险后再动手。本站仅提供固件分发与安装说明，与 Tesla, Inc. 无关。
